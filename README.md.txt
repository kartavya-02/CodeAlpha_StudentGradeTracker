# Student Grade Tracker

## Project Description
The Student Grade Tracker is a Java-based application that helps manage student marks and calculate their academic performance.

## Features
- Enter student names and marks.
- Store student information using arrays.
- Calculate average marks.
- Find the highest marks.
- Find the lowest marks.
- Display a summary report of all students.

## Technologies Used
- Java
- Scanner Class
- Arrays
- Loops and Conditional Statements

## How to Run
1. Download the project files.
2. Open the project in VS Code or any Java IDE.
3. Compile the program:
   `javac StudentGradeTracker.java`
4. Run the program:
   `java StudentGradeTracker`
